# NVO987

**NVO987 — Open Decentralized Web Infrastructure**

Website: https://nvo987.us/

NVO987 is a distributed personal infrastructure connecting identity,
research, archives, publishing, media, decentralized networks, data,
cryptography, and persistent digital identifiers.

The infrastructure is presented through the NEXARIUM architecture.

## Architecture

NEXARIUM is organized into three conceptual layers:

1. **Individual** — personal identity, research, archives, publishing,
   media, decentralized services, data, cryptography, and identifiers.
2. **Institution** — cultural, artistic, educational, and research activity.
3. **Civilisation** — interconnected infrastructure for the long-term
   management and accessibility of knowledge and digital systems.
